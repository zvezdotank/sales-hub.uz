# Sales Hub — sales-hub.uz

Статический сайт агентства интернет-рекламы. Без фреймворков и зависимостей —
чистые HTML, CSS и JavaScript. Публикуется через GitHub Pages.

## Главное, что нужно знать

**HTML-файлы в корне генерируются автоматически. Не правьте их руками** —
изменения потеряются при следующей сборке. Правьте `site.json` и `templates/`.

```
site.json          ← все тексты, контакты, услуги, FAQ
templates/         ← разметка (шапка, подвал, страницы)
tools/             ← скрипты сборки
assets/img/_src/   ← оригиналы фотографий

*.html             ← результат сборки, коммитится в репозиторий
```

## Как что-то поменять

### Телефон, Telegram, почту

Откройте `site.json`, блок `"site"`. Поменяйте значение и пересоберите:

```bash
python3 tools/build-site.py
```

Контакт обновится сразу на всех девяти страницах и в микроразметке.

### Текст услуги или добавить новую

Всё в `site.json`, массив `"services"`. Каждая услуга — один объект: заголовки,
описания, список того, что входит, этапы работы, meta-теги. Новый объект в этом
массиве = новая страница, карточка на главной, пункт в меню героя, строка в
подвале и запись в `sitemap.xml`. Ничего дописывать вручную не нужно.

Поле `"slug"` задаёт имя файла: `"slug": "seo"` → `seo.html`.

### Вопросы и ответы

`site.json`, массив `"faq"`. Попадают и на страницу, и в микроразметку
`FAQPage` — Google умеет показывать их прямо в выдаче.

### Цифры и метрики

`site.json`: `heroStats` (полосы в панели героя), `heroBar` (лента под героем),
`resultStats` (счётчики в блоке «Результаты»).

> Каждая цифра на сайте должна быть защитима перед клиентом. Сейчас там
> значения-заготовки — замените на свои подтверждённые данные.

### Логотипы клиентов

Список — в `tools/build-site.py`, константа `CLIENTS`. Марки нарисованы
SVG-кодом там же, в `CLIENT_MARKS`: монохромные, в одной оптической сетке 32×32,
чтобы разнородные бренды читались как один ряд. Это **не** репродукции
товарных знаков. Когда клиенты предоставят официальные логотипы, замените
содержимое марок на их SVG — вёрстку менять не придётся.

### Портфолио на странице «Веб-разработка»

Список работ — в `site.json`, у услуги `web-dev` блок `"portfolio"`. Каждая
работа: домен, ссылка, направление, тип, описание и метки.

**Фильтр по направлениям** собирается сам. Порядок кнопок задаёт массив
`"filters"`, направление работы — поле `"category"`. Кнопка появляется на
сайте, только если в этом направлении есть хотя бы одна работа: пока нет ни
одного ресторана, кнопки «Рестораны» не будет, а как только добавите первый —
она появится сама. Если направлений меньше двух, фильтр не показывается
вовсе. Направление, которого нет в `"filters"`, не потеряется — кнопка встанет
в конец ряда.

Снимки страниц делает отдельный скрипт:

```bash
python3 tools/build-portfolio.py             # переснять все
python3 tools/build-portfolio.py dosug       # только один сайт, по slug
```

Он открывает каждый сайт в невидимом окне Chrome, прокручивает сверху донизу
(чтобы подгрузились картинки), снимает **страницу целиком** одним кадром и
кладёт AVIF + WebP в `assets/img/portfolio/`. Высота кадра записывается в
`manifest.json` — из неё сборщик считает, за сколько секунд кадр прокручивается
при наведении.

Пара вещей, о которые скрипт спотыкался и которые уже обойдены: сайты с
секциями в единицах `vh` растягиваются вслед за окном (поэтому окно обычное, а
за его пределы снимает протокол DevTools), встроенные ролики YouTube в
невидимом окне рисуют чёрный прямоугольник (подставляется обложка ролика), а
всплывающие виджеты обратного звонка убираются из кадра.

Если сайт ещё не опубликован или у него не выпущен сертификат, у работы можно
указать `"shotUrl"` — адрес локального сервера с теми же файлами. Не ответит —
скрипт снимет с публичного адреса.

### Бриф на странице услуги

Бриф выводится у той услуги, где в `site.json` есть блок `"brief"` — сейчас
это «Контекстная реклама». Там же задаются заголовок, варианты целей
(`goals`) и подсказки по географии (`geo`). Чтобы поставить бриф на другую
услугу, скопируйте блок к ней — разметка и скрипт подхватятся сами.

Обязательные поля: название компании, цель, бюджет, география и контакт.
Сайт и соцсети — по желанию. Поле «Как с вами связаться» я добавил к вашему
списку вопросов: без него бриф некуда отвечать.

Ответы уходят тем же обработчиком, что и обычная форма заявки, — адрес берётся
из `site.formEndpoint`. Пока он пуст, бриф честно предлагает написать в
Telegram и не делает вид, что заявка ушла.

### Фотографии

Положите оригинал в `assets/img/_src/`, добавьте его в словарь `PLAN` внутри
`tools/build-images.py` и запустите:

```bash
python3 tools/build-images.py
```

Скрипт сам сделает AVIF и WebP в нужных размерах и запишет реальные размеры в
`manifest.json` — из них подставляются атрибуты `width`/`height`, чтобы вёрстка
не «прыгала» при загрузке.

## Сборка

```bash
python3 tools/build-site.py      # собрать страницы, robots.txt и sitemap.xml
python3 tools/check-links.py     # проверить ссылки и якоря
python3 tools/build-images.py    # пересобрать изображения (нужен Pillow)
python3 tools/build-portfolio.py # переснять сайты для блока работ (нужен Chrome)
python3 tools/build-og.py        # пересобрать картинку превью для соцсетей
python3 tools/grade-telegram.py  # day-for-night для фото антенны (см. ниже)
```

Для картинок нужен Pillow: `pip3 install --user Pillow`, для `grade-telegram.py`
дополнительно NumPy. Для страниц и проверки ссылок — только Python 3.9+.

### Про фото для услуги Telegram

Все изображения сайта — тёмные кинематографичные рендеры с тёплым оранжевым
светом. Исходное фото антенны (`service-telegram.jpg`) единственное выбивалось:
дневная документальная съёмка с ярко-голубым небом и белым солнцем.

`tools/grade-telegram.py` переводит его в ночь: гасит небо до глубокого синего,
превращает солнце в тёплый источник и подсвечивает им конструкцию. Результат —
`service-telegram-night.jpg`, именно он указан в `site.json` и в `PLAN` внутри
`build-images.py`. Оригинал остаётся рядом, так что грейд можно перенастроить
или откатить. Если появится подходящее изображение в общей стилистике —
просто положите его в `_src` и поменяйте `"img"` у услуги.

## Локальный просмотр

```bash
python3 -m http.server 4173
```

Затем откройте http://localhost:4173

## Что осталось подключить

**Форма заявки никуда не отправляет данные.** Сейчас она проверяет поля и
честно предлагает написать в Telegram. Чтобы включить отправку, впишите адрес
обработчика в `js/main.js`, константа `FORM_ENDPOINT` — остальной код
(отправка, состояния кнопки, обработка ошибок) уже готов. Подойдёт Formspree,
Web3Forms, собственный бэкенд или Telegram-бот.

**Политику конфиденциальности** (`templates/privacy.html`) стоит согласовать с
юристом и указать реквизиты юрлица — сейчас это типовая заготовка.
